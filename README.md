# Ajmal-Portfolio

Mohammed Ajmal's Personal Portfolio Website built with Next.js, React, Tailwind CSS, and TypeScript.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js
- **UI / Library:** React
- **Styling:** Tailwind CSS
- **Icons:** React Icons
- **Language:** TypeScript
